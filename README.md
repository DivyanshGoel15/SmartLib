# SmartLib
Department-Wise Library Reservation &amp; Dynamic Priority System


tudent, Faculty and Library Administration portals with localStorage/sessionStorage.

Features: strong password validation, role-based routing, student profile/exam/reservation summary, faculty department-specific exam management and resource access, library-wide student directory with search/filter/sort/remove, exam management, and portal-wide typography/footer polish.

This is a JavaScript evaluation prototype; localStorage is not production authentication.
